# pokeUMAP - ポケモン類似度 2次元マップ & PokeDB

PokeAPI (https://pokeapi.co/) から全国図鑑 No.1 (フシギダネ) から No.1025 (モモワロウ) までのすべてのポケモンの情報を取得し、SQLite データベース (`pokemon.db`) および JSON データセット (`pokemon_database.json`) を自動構築するプロジェクトです。

---

## 🌟 特徴

* **日本語名 & 全ゲームバージョンの図鑑説明文を完全網羅**
  * カタカナ/漢字名 (`name_ja`)、ひらがな名 (`name_kana`)、英語名 (`name_en`)。
  * 代表的な日本語図鑑説明 (`flavor_text_ja`) に加え、赤・緑・金・銀〜スカーレット・バイオレット等の各バージョンごとの日本語説明文をサブテーブル (`flavor_texts`) にすべて保存。
* **充実したステータス & 属性情報**
  * 種族値 (HP, 攻撃, 防御, 特攻, 特防, 素早さ, 合計)
  * タイプ1, タイプ2
  * 高さ(m), 重さ(kg), 分類(例: たねポケモン), 世代, 伝説/幻フラグ
  * ドット絵画像URL, 公式イラストURL
* **高速な取得処理** (マルチスレッド並列通信 & 自動リトライ機能)
* **検証・検索ツールの付属**

## 🚀 使い方

### 1. データベースの再構築 / 更新
Python 標準ライブラリのみで動作します（外部ライブラリ不要）。

```bash
python fetch_and_build_db.py
```

### 2. データベースの自動検証テスト
データベースの件数（1,025件）、Nullチェック、データ構造の一致を自動チェックします。

```bash
python verify_db.py
```

### 3. ポケモンの検索・閲覧 (CLI)
図鑑番号や名前（日本語・英語・ひらがな）で検索できます。

```bash
# 図鑑番号で検索
python query_pokemon.py 25

# 日本語名で検索
python query_pokemon.py ピカチュウ

# あいまい検索
python query_pokemon.py リザードン
```

## 🗺️ ポケモン類似度 2次元マップ アプリケーション (1～500番)

日本語図鑑本文だけから意味特徴を作り、2次元空間へアイコンを配置する Web アプリケーションです。タイプと分類 (`genus_ja`) は評価・表示専用で、学習や所属領域の決定には使用しません。

SudachiPy の語・複合語 TF-IDF と E5 埋め込みを組み合わせ、7〜9個の主要領域から品質指標で最適数を選びます。UMAP 座標は意味的なアンカーとして保持し、ノード・領域ラベルは決定的な衝突回避処理で配置します。

### 🚀 マップの起動手順

1. **マップ専用依存関係の導入**:
   ```bash
   pip install -r requirements-map.txt
   ```

2. **Web サーバーの起動**:
   ```bash
   python server.py
   ```

3. **ブラウザでアクセス**:
   ブラウザで [http://localhost:8000](http://localhost:8000) にアクセスします。

座標・領域・ラベルをデータベースから再構築する場合は `python build_umap_coords.py`、生成物だけを検証する場合は `python verify_map_quality.py` を実行します。再構築は一時ファイルの検証に成功した場合だけ、JSON とモデルを置換します。

### ✨ 主な機能

* **インタラクティブ 2D マップ**: マウスホイールでズーム、ドラッグで自由パン移動。ドット絵アイコンを描画。
* **検索・タイプフィルタ**: 名前や番号でヒットしたポケモンへ即座にカメラ移動、タイプ別強調表示。
* **ドラッグ＆ドロップ座標変更**: マップ上のアイコンをドラッグして座標を自由に調整可能。
* **新規ポケモンの追加 & AI座標自動計算**: 画面上から新しいポケモンを追加でき、「AI自動計算」ボタンで説明文から最適な (X, Y) 座標を自動充填。
* **データの永続保存**: 画面の「保存」ボタンでユーザーの調整データを `pokemon_map_data.json` に即時保存。
