# PokeAPI ポケモンデータベース仕様書

本ドキュメントは、PokeAPI (https://pokeapi.co/) より取得したポケモン全データをもとに構築された SQLite データベース (`pokemon.db`) および JSON データセット (`pokemon_database.json`) の構造と仕様を定義します。

---

## 1. データベース概要

* **データベースファイル名**: `pokemon.db` (SQLite3)
* **副出力フォーマット**: `pokemon_database.json` (JSON)
* **収録データ数**: 1,025 種（全国図鑑 No.1 ～ No.1025）
* **文字コード**: UTF-8

---

## 2. テーブル定義 (ER Schema)

### 2.1 メインテーブル: `pokemons`

ポケモンの基本情報、日本語/英語名、分類、タイプ、種族値、代表的な図鑑説明などを保持します。

| カラム名 | データ型 | 制約 | 説明 |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY | 全国図鑑番号 (1 ～ 1025) |
| `name_ja` | TEXT | NOT NULL | 日本語名（漢字/カタカナ表記） |
| `name_kana` | TEXT | NOT NULL | 日本語名（ひらがな/カタカナ表記） |
| `name_en` | TEXT | NOT NULL | 英語名 |
| `genus_ja` | TEXT | | 日本語分類（例: たねポケモン） |
| `generation` | INTEGER | | 登場世代 (1 ～ 9) |
| `type1` | TEXT | NOT NULL | タイプ1（英語名: fire, water等） |
| `type2` | TEXT | | タイプ2（無ければNULL） |
| `height` | REAL | | 高さ (m) |
| `weight` | REAL | | 重さ (kg) |
| `hp` | INTEGER | NOT NULL | 種族値: HP |
| `attack` | INTEGER | NOT NULL | 種族値: 攻撃 |
| `defense` | INTEGER | NOT NULL | 種族値: 防御 |
| `special_attack` | INTEGER | NOT NULL | 種族値: 特攻 |
| `special_defense` | INTEGER | NOT NULL | 種族値: 特防 |
| `speed` | INTEGER | NOT NULL | 種族値: 素早さ |
| `base_stats_total` | INTEGER | NOT NULL | 種族値合計 |
| `is_legendary` | INTEGER | NOT NULL | 伝説のポケモンフラグ (0: 通常, 1: 伝説) |
| `is_mythical` | INTEGER | NOT NULL | 幻のポケモンフラグ (0: 通常, 1: 幻) |
| `flavor_text_ja` | TEXT | | 代表的な日本語図鑑説明文 |
| `sprite_url` | TEXT | | ドット絵画像URL |
| `artwork_url` | TEXT | | 公式イラスト画像URL |

### 2.2 サブテーブル: `flavor_texts`

ポケモン各世代・ゲームバージョンごとの日本語図鑑説明を保持します。

| カラム名 | データ型 | 制約 | 説明 |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 一意のID |
| `pokemon_id` | INTEGER | FOREIGN KEY (`pokemons.id`) | 対象ポケモンの全国図鑑番号 |
| `version_name` | TEXT | NOT NULL | ゲームバージョン名（例: red, blue, violet 等） |
| `language` | TEXT | NOT NULL | 言語コード (`ja`: 漢字/カタカナ, `ja-Hrkt`: ひらがな) |
| `flavor_text` | TEXT | NOT NULL | 図鑑説明文 |

## 3. サンプル SQL クエリ

### ポケモン名と代表的な図鑑説明の検索
```sql
SELECT id, name_ja, genus_ja, flavor_text_ja
FROM pokemons
WHERE name_ja = 'ピカチュウ';
```

### バージョンごとのすべての図鑑説明を取得
```sql
SELECT p.name_ja, f.version_name, f.flavor_text
FROM pokemons p
JOIN flavor_texts f ON p.id = f.pokemon_id
WHERE p.id = 25 AND f.language = 'ja';
```

### 種族値合計が高い上位10匹を検索
```sql
SELECT id, name_ja, type1, type2, base_stats_total, hp, attack, defense, special_attack, special_defense, speed
FROM pokemons
ORDER BY base_stats_total DESC
LIMIT 10;
```
