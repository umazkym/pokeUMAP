# ポケモン類似度 2次元マップシステム仕様書 (1～500番)

本ドキュメントは、ポケモンの「図鑑説明 (`flavor_text_ja`)」テキストを唯一の指標とし、意味的類似度に基づく 2次元次元削減マッピング（Embedding + UMAP）とインタラクティブ可視化 Web アプリケーションの仕様について解説します。
また、将来的な未知の解説文や、ポケモンとは無関係な自己紹介文・自由文が入力された場合でも、学習済みの意味空間へ自然に射影・プロットできる設計となっています。

---

## 1. 概要

* **対象範囲**: 全国図鑑 No.1 (フシギダネ) ～ No.500 (レジギガス)
* **指標属性**:
  * 日本語図鑑説明文のみを分類に使用します。既存ポケモンは代表文を先頭に、重複除去した図鑑本文を最大6件まで使って短文の情報欠落を補います。タイプと分類は表示・品質診断専用で、特徴量には加えません。
* **モデル構成**:
  * ベクトル化（Embedding）: `intfloat/multilingual-e5-small` (SentenceTransformer)
    * 本文全体ビュー 35% + Sudachi自立語だけの概念ビュー 65%。どちらも `passage:` プレフィックスで同一意味空間へ埋め込み、短文の文法構造がクラスタを支配するのを抑制します。
  * 日本語概念抽出: SudachiPy（分割モードC）による自立語・複合語TF-IDFと文字n-gramフォールバック
  * ハイブリッド特徴: 正規化E5埋め込み 65% + SVD圧縮した疎概念特徴 35%
  * マクロ領域: KMeansの7・8・9領域を品質指標で比較し、自動選択
  * 2次元座標変換: `umap.UMAP(n_neighbors=20, min_dist=0.18, spread=2.0, n_components=2, metric='cosine', random_state=42)`
  * 表示配置: 2〜98パーセンタイル正規化後、中心間隔28を保証する衝突緩和処理
  * 表示コントラスト: 保存用の意味座標は維持したまま、描画時に領域内距離を70%へ圧縮し、領域中心を1.45倍に拡張したうえで領域同士の重なりを緩和します。ドラッグ操作は逆変換して意味座標へ保存します。
  * 比較表示: 同一ページの「修正前／修正後」タブで切り替えます。クエリ `?view=before` と `?view=after` で各表示へ直接リンクでき、クエリ省略時は既存の修正前表示を維持します。
  * 品質診断: 第一タイプのクラスタ別最多比率と全体加重純度をJSONに記録します。診断のみに使い、学習・所属決定には使いません。
* **機能**:
  * ポケモンの解説文の類似性に応じた 2次元空間プロット＆アイコン描画
  * マウス操作によるズーム・パン、タイプ別フィルタ、名前/番号検索
  * **選択ノードからの類似ネットワーク発光ライン描画**（最も近い上位4匹へ動的リンク）
  * **サイドバーでのAI類似分析表示**（共通キーワードタグ、AI解説要約、類似度％付き近傍ポケモンTOP4リスト、共通単語ハイライト、ワンクリックジャンプ）
  * **ユーザーによる座標変更・ドラッグドロップ編集・新規ポケモン追加**
  * **AI自動座標計算機能 & 配置理由プレビュー**（新規の解説文やオリジナルの自己紹介文を入力すると、近似座標およびマッチした近傍ポケモン・共通トピック理由を即座に算出・表示）

## 3. Web API 仕様 (`server.py`)

### `GET /api/pokemon`
* **説明**: マップ描画用の最新データ (`pokemon_map_data.json`) を取得します。
* **返却フォーマット**: モデル・レイアウト版と品質指標を含む `meta`、`clusters`、`pokemons` のJSONオブジェクト。各ポケモンは `cluster_id` を持ちます。

### `POST /api/pokemon/save`
* **説明**: ユーザーがドラッグまたは数値を指定して更新した座標・新規追加ポケモンのデータを永続保存します。
* **リクエストボディ**: `meta`、`clusters`、`pokemons` を含むJSONオブジェクト。手動座標と `cluster_id` を分離して保存します。

### `POST /api/pokemon/calculate_coord`
* **説明**: ポケモンの図鑑説明文、新規解説文、または自由な自己紹介文 (`flavor_text_ja`) から、学習済み SentenceTransformer + UMAP モデルで既存マップ上の最適な (X, Y) 座標を自動計算します。新規1文の所属は、同じ結合特徴空間の近傍9件と、学習データから自動生成したクラスタラベルとのE5意味類似度を統合して `cluster_id` を決めます。入力本文が自動生成 `top_words` をSudachi原形または部分文字列で直接支持する場合は、語彙支持60%・ラベル意味30%・近傍10%とし、直接支持がない場合はラベル意味90%・近傍10%とします。固定のポケモン辞書は使用しません。
* **リクエストボディ**:
  ```json
  {
    "flavor_text_ja": "休日はカフェでのんびり読書をして過ごすのが好きな温厚な性格。"
  }
  ```
* **返却値**:
  ```json
  {
    "status": "ok",
    "x": 482.35,
    "y": 420.10,
    "anchor_x": 474.12,
    "anchor_y": 416.88,
    "cluster_id": 6,
    "cluster_keywords": ["葉っぱ", "栄養"]
  }
  ```

## 4. 起動手順

1. マップ用依存関係の導入:
   ```bash
   pip install -r requirements-map.txt
   ```
2. サーバーの起動:
   ```bash
   python server.py
   ```
3. ブラウザでアクセス:
   `http://localhost:8000` を開く。
